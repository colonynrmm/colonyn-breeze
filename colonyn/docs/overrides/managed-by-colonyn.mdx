The page you followed describes how to run the server behind the platform: installation, configuration, upgrades, server backups, certificates and infrastructure monitoring. On Colonyn, the Colonyn team does all of this for you at **my.colonyn.com**. There is nothing to install or configure on your side.

What you manage yourself:

- **Your devices**: install the agent from [Installation](/agents/installation/) and manage enrollment from [Enrollment keys](/agents/enrollment-keys/).
- **Your team**: invite technicians and set permissions in [Users & roles](/reference/users-and-roles/).
- **Your subscription**: plan, modules, technician seats and invoices under **My RMM services** at [www.colonyn.com](https://www.colonyn.com/my/rmm).

If a feature needs a server-side setting that you cannot change from the dashboard, [contact us](https://www.colonyn.com/contactus) and tell us what you need.
